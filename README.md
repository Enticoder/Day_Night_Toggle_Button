## Day/Night Toggle UI Demo

This project demonstrates a pure CSS day/night toggle switch with animated sun and moon icons.  
The background and icons smoothly transition between light and dark modes when toggled.

## Features

- Animated toggle switch with SVG sun and moon icons
- Responsive design for mobile, tablet, and desktop
- Pure HTML and CSS implementation (no JavaScript required)

## Usage

1. Open `index.html` in your browser.
2. Click the toggle switch to change between day and night modes.

## Files

- `index.html` — Main HTML file with the toggle UI
- `style.css` — CSS for layout, animation, and responsiveness
