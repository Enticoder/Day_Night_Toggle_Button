# Animated Border Cards Demo

This project showcases creative CSS border animations for card UI elements. It includes two main demos:

- **Simple Border Animation**: A card with a rotating colored border effect on hover.
- **White Light Border Animation**: A card with a rotating white light border effect on hover.

## Structure

- `DN/` — Day/Night toggle UI demo
- `HOVER/` — Animated border card demos
  - `Green UI/` — 3D UI card with glassmorphism and social buttons
  - `HOVER1/` — Alternate border animation demo
